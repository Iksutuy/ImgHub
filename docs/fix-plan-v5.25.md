## 一、问题与根因

### A. 顶栏「就绪」徽标文字不居中

**根因**：全局 `Style Selector="Button"` 设了 `MinHeight=34` + `Padding=14,7`，
胶囊徽标（`CornerRadius=10, Padding=8,2`）被 `MinHeight=34` 顶高 → 文字在 34px 里偏上。

**修复**：徽标改用 `Border` + `TextBlock`（不用 Button 的全局最小高度），
或显式 `MinHeight="22"`。用 Border 更干净（它本质是状态标签，不是主按钮），
点击行为改由 `PointerPressed` 事件保留。

**顺带**：标题栏 `Status` 与顶栏徽标**重复** → 标题栏那个去掉（顶栏已有自检徽标）。

### B. 左栏下拉框高度不足、字底被遮挡

**根因**：`MinHeight=38` 是**最小**值，FluentTheme 的 ComboBox 模板内部
仍有自己的 `Padding`/`MinHeight`，中文字体（Noto Sans SC）行高较大，
加上 `StyledProperty` 的 `Padding` 未覆盖模板内部 → 文字下缘被裁。

**修复**：给全局 `ComboBox` 显式设置 `Padding` 与 `MinHeight=40`，
并在模板层（`/template/ ContentPresenter`）设 `VerticalContentAlignment=Center`。
**用实测验证**（放大截图看字底）。

### C. 「用标注编辑」按钮超长/被裁

**根因**：工具栏 `WrapPanel` 里该按钮 `MinWidth=96` + 全局 `Padding=14,7`，
在 375px 宽的中栏里与「清除/复位/＋/−」同行 → 总宽超出 → 被 `ClipToBounds` 裁掉。

**修复**：编辑工具栏改为**网格化三行**（工具行 / 缩放行 / 操作行），
每行 `WrapPanel` 自动换行；「用标注编辑」给足宽度并置于行尾。
**实测验收**：该按钮右缘 < 中栏卡片右缘。

### D. 统一对齐所有 UI 与文字

**根因**：多处标签列宽不一（左栏 `64`、设置浮层 `96`），
TextBlock 未统一 `VerticalAlignment=Center`，按钮内容未统一居中。

**修复**：
- 抽 `Classes="fieldLabel"`（统一 FontSize=13 / 右对齐 / 垂直居中 / 固定宽 64）
- 所有行内按钮内容统一 `VerticalAlignment="Center" "HorizontalAlignment="Center"`
- 卡片内边距统一（`Padding=14`），间距统一（`Spacing=10`）

### E. 🔴 缩放 / 复位**完全不起效**（用户追加）

**根因（已定位）**：`RegionCanvas` 的 `_zoom/_panX/_panY` 只作用于
**它自己绘制的标注**；而**底图是 Grid 里另一个独立的 `Image` 控件**，
不参与任何变换 → 点缩放时只有标注在动（没标注时视觉零变化）→ 「完全不起效」。

**修复**：让底图与标注**共用同一个变换矩阵**：
1. `RegionCanvas` 暴露 `ViewMatrix` 属性 + `ViewChanged` 事件（缩放/平移/复位时触发）
2. `MainView.axaml.cs` 订阅 → 把同一个 `MatrixTransform` 同步给 `Image.RenderTransform`
3. 非编辑模式复位 `Image.RenderTransform`（避免残留）

> 为什么用「共享矩阵」而不是「让画布自己画底图」：后者要改动可见性与交互逻辑
> （画布原本只在编辑模式可见），风险大；共享矩阵是**最小且像素级一致**的改法。

**验收**：探针点 `＋` 后，图片的 `RenderTransform` 非空且矩阵缩放值 > 1；
点「复位」后回到单位矩阵。

### F. 左栏「清空」按钮与滚动条重叠（用户追加）

**根因**：左栏 `Grid ColumnDefinitions="*,18"`，内容 StackPanel 的右 Margin=10，
但**按钮行没有右边界约束** → 4 个按钮横排时总宽超出内容列，压在滚动条列上。

**修复**：按钮行改 `WrapPanel` 自动换行；内容列右侧留足 12px；
滚动条列加 `Margin` 使其与内容有可见间隙。

### G. 全按钮功能与流程核查（用户追加）

逐一点击实测（编辑模式开），确认：
- 生成 / 编辑 / 润色 / 清空（文案）
- 编辑图片 / 工具下拉 / 粗细滑块 / 调色板 / 缩放 −＋ / 复位 / 清除 / 用标注编辑
- 系统看图器 / 保存到相册
- 导入 / 多选 / 删除选中 / 移除选中 / 历史右键两项 / 提示词历史右键
- 顶栏：provider 下拉 / 深色 / 设置（含校验、保存、日志目录）
- 窗口：最小化 / 最大化 / 关闭

### H. UI 美化（用户授权自行优化）

- 统一圆角（卡片 10 / 控件 8 / 胶囊 999）
- 统一描边（`AppBorderBrush`，卡片 1px）
- 卡片内间距统一 `14`；分组标题 `.section` 统一
- 状态色：`就绪`（绿）/`未就绪`（橙）区分，而非都用强调蓝
- 按钮层级：主操作 `accent`、次操作默认、工具 `toolbar`
