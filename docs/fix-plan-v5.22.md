## 诊断结论（先查明根因再动手）

| # | 现象 | 根因（已定位） |
|---|---|---|
| 1 | 设置保存崩溃 | **`LoadApiKey()` 在属性 getter 里做文件 IO 且无异常保护** —— `IsConfigured`/`KeyStatusText`/`RefreshKeyStatus` 都走它。绑定求值时抛异常 → UI 线程崩溃 |
| 2 | 提供商累计 ≠ 总累计 | **口径不一致**：`TotalCost` 累加 API 实际值，`Items[].Cost` 是**均摊值**（`res.Cost / N`）。另 `CostForProvider` 对**无 provider 字段的旧数据**按"当前 provider"计入 → 切换 provider 时数字漂移 |
| 5 | 撤回崩溃 + 意义不明 | 同 #1（命令内间接调 IO/刷新链）。语义问题：撤回只是"从当前指针移除"，**文件不删**，用户不理解为何不删 |
| — | 版本号变 `n.0` | 上一轮 Python 替换脚本把 `5.19.0` 误替换为 `n.0`（正则未锚定） |

## 14 项修复方案

### 1. 设置保存崩溃
- `LoadApiKey()` 包 try/catch（IO 失败返回空串）
- `IsConfigured` / `KeyStatusText` 改为**缓存字段**，不再每次绑定都读文件
- 所有 `[RelayCommand]` 的同步方法通过统一包装器执行（异常转日志，不崩进程）

### 2. 提供商累计与总累计统一口径
- **总累计 = `Items.Sum(Cost)`**（不再单独累加，避免漂移）
- **提供商累计 = 按 `Item.Provider` 分组求和**（同一数据源 → 天然一致）
- 旧数据无 provider 字段 → 归入 `"unknown"` 组并**在 UI 标注**，不再漂移

### 3. 离线按钮改为 debug 功能
- 从主界面移除「离线」复选框
- 迁到**设置 → 开发者选项**，且需 `IMGHUB_DEBUG=1` 环境变量才显示

### 4. 编辑图片的放大缩小（标记随动且不乱移位）
- 已有滚轮/按钮缩放（#7 上一轮）
- **确保标记不错位**：核对变换矩阵与 `ToNormalized` 逆变换的一致性（缩放中心 = 控件中心）
- 加"缩放百分比"显示 + `适应窗口` 按钮

### 5. 撤回崩溃 + 语义明确
- 修复崩溃（同 #1 的统一异常包装）
- **改名为「移除当前」**，并让语义明确：
  - 仅从历史指针移除（文件保留在磁盘）
  - 提示文案写明"图片文件仍在数据目录"
  - 提供「删除文件」选项（配合 #11 右键删除）

### 6. 设置按钮移到右上角
- 从底栏移除 ⚙ 设置
- 放到顶栏右侧「深色」按钮**旁边**

### 7. 图标化 + 设置里可开关
- 所有主要按钮加图标（Segoe MDL2 / Fluent 字形）
- 主题切换（深色/浅色）+ 图标显示 在**设置界面可开关**
- 新增 `UseIcons` 配置项（持久化）

### 8. 底栏暂时隐藏
- 底栏整体 `IsVisible=false`（保留结构，留待后续新功能）

### 9. 质量默认 auto
- `AppConfig.Quality` 默认值 `low` → `"auto"`
- 首次运行（无 config）时用 auto

### 10. 价格预估按「provider + 模型」绑定，存 JSON
- 新建 `model_stats.json`：`{ "openrouter|model-x": { calls, totalCost, avgCost }, ... }`
- 预估逻辑：
  - **用过该模型** → 用该模型的历史 **平均花费**
  - **没用过** → **不显示预估**（避免误导）
- 每次生成成功后更新统计

### 11. 历史 / 提示词历史支持右键删除
- 历史列表项：右键菜单「删除（含文件）」
- 提示词历史条目：右键「删除」

### 12. 历史与提示词历史保存为可读 JSON
- `history.jsonl` → 保持 JSONL（**可读**、逐行可删），另导出 `history.json` 汇总
- `prompt_history.jsonl` 同上
- 提供「打开数据目录」按钮便于手动编辑/删除

### 13. 润色提示词 → 「润色」；加「清空」按钮
- 按钮文案改为「润色」
- 在「导入」原位置加「清空」按钮（清空提示词输入 + 清空标注）

### 14. 导入按钮移位
- 「导入」从主操作区移到 **历史/累计 面板后方**
