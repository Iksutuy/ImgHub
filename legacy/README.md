## 一、安装

### A. Termux

```bash
# 1. 装 Python
pkg install python

# 2.（必须，只需一次）授权访问手机存储，会弹权限框
termux-setup-storage

# 3.（推荐）装预览工具 —— 效果远好于自带字符画
pkg install chafa

# 4. 解压并运行
cd ~/storage/downloads
unzip imgagent-5.17.0-termux.zip
cd imgagent-termux
python3 main.py
```

> **Termux 小技巧**：软键盘上的 `CTRL` 键可以配合字母使用。
> 例如 `CTRL` + `g` = 生成，`CTRL` + `q` = 退出。
> 想固定显示 CTRL：长按软键盘左下角的 `ESC` 键。

### B. Pydroid 3

1. 把 `imgagent-5.17.0-pydroid3.zip` 解压到手机任意目录
2. Pydroid 3 里打开 `main.py`，点运行（▶）
3. 首次运行会问"要不要用 AI 润色" —— 需要 API key 才能用

**Pydroid 额外选项**（想要系统看图器 / 相册读取）：
装 `Pydroid repository plugin` + `pip install pyjnius`，
然后在菜单里按 `Ctrl+N` 看环境状态确认。

### C. Windows（桌面版）

> 需要 Python 3.10+（建议 3.12 / 3.13），在 [python.org](https://www.python.org/downloads/)
> 安装时勾选 **Add Python to PATH**。

```powershell
# 1.（推荐，TUI 必装）装 windows-curses 之后才能用全屏 TUI 界面
pip install windows-curses
#    不装也能用：自动降级为命令行菜单（生成/编辑/历史都可用）
#    注：程序已针对 Windows 的 PDCurses 做了按键兼容（方向键/中文/快捷键均实测可用）

# 2. 解压后进入目录运行
cd imgagent-windows
python main.py

# 3. 想跑通流程不花钱：离线模式（占位图）
python main.py --offline
```

**双击运行**：zip 里的 `启动.bat`（自动切 UTF-8 代码页 + 启动）。

> **Windows 小技巧**：推荐在 **Windows Terminal** 或 PowerShell 7 里运行
> （自带 UTF-8，中文和边框最漂亮）；老版 cmd 若中文乱码，先执行 `chcp 65001`。

**数据目录**：默认脚本同目录的 `imgagent_data/`（可写时），否则 `%LOCALAPPDATA%\imgagent`。
生成的图片优先存到 `我的图片\imgagent\`（资源管理器可见）。

> **终端兼容**：程序会自动为 Windows 控制台开启 ANSI 颜色；老系统开不了时
> 自动关闭颜色（避免出现 `←[90m` 这类乱码），功能不受影响。

**提示词润色（可选）**：润色用的 LLM 端点/模型/key **需要你自配**（程序不含任何内置凭据）。
在 `Ctrl+S` → 设置里：
- 命令行版：选 `12) 配置润色`，填端点 / 模型 / key（留空则跳过该项）
- TUI 版：设置 → `配置润色`

配置会持久化到数据目录（端点/模型存 `config.json`，key 存 `.imgagent_polish_key`），
下次启动自动生效。也可用环境变量 `IMGAGENT_POLISH_BASE_URL / _MODEL / _API_KEY`。
**未配置 key 时润色自动关闭**，不影响生图主流程。

### D. 首次配置 API key

按 `Ctrl+S` 打开设置 → 选「API key」→ 输入。支持两个 provider：

| provider | 说明 |
|---|---|
| **OpenRouter** | 模型清单走 `/images/models`，无需 key |
| **APIMart** | 需要 key，支持 `xhigh`/`max` 质量档（2.5 系模型） |

| `Ctrl+D` | 编辑当前图 | | `Ctrl+T` | 按键帮助 |

## 四、提示词不会丢

两个保障：

1. **提交时立即记入历史**（`prompt_history.jsonl`），不管后面成不成功。
   所以哪怕 401 失败、网络断了，提示词都在。
2. **失败自动放回输入框** + `↑` 随时翻回来。

```
你打了：一只猫在窗台上，逆光，胶片感，浅景深...
    ↓ Enter
   （假如 401 失败）
    ↓
输入框自动恢复：一只猫在窗台上，逆光，胶片感，浅景深...
消息面板提示：生成未成功，提示词已放回输入框（↑ 可翻更早的）
```

`↑` 往更早翻，`↓` 往更新翻；一直按 `↓` 会回到你**原本正在打的草稿**。

历史存在数据目录的 `prompt_history.jsonl`（最多 200 条，自动去重裁剪），
按 `Ctrl+I` 可以看到确切路径。

## 五、编辑（改图）—— 两个概念要分清

### 概念

| 概念 | 是什么 | 怎么选 | 数量 |
|---|---|---|---|
| **待修改图** | 要被改的那张（主体 / 底图） | `PgUp` / `PgDn` | 1 张 |
| **参考图** | 提供人物设定 / 场景 / 风格 | `Ctrl+Y` 弹列表 | 最多 4 张 |

```
左下角长这样：
╭─┤ 待修改图 + 参考图 2/4 ├──────────────╮
│ ▶ 待修改 [#3] my_photo.png             │  ← PgUp/PgDn 选
│   参考图 2/4（Ctrl+Y 加/删）            │
│ ▶ 1) [#1] style_ref.png                │  ← Home/End 选
│   2) [#5] face_ref.png                 │     Ctrl+K 删
│  Home/End 选参考图 · Ctrl+K 删 · Ctrl+D 改图 │
╰────────────────────────────────────────╯
```

### 用法

```
① PgUp/PgDn 选出「待修改图」
② Ctrl+Y 选出「参考图」（可以多张）
③ 输入要求（如「把人物换成参考图的风格，场景改成雪原」）
④ Ctrl+D
```

**输出 = 用参考图的设定去改「待修改图」**，不是参考图本身。

### 为什么能这样？（实测依据）

APIMart 的 `image_urls` **顺序有语义**：第 1 张是主体，后面的是参考。
程序固定把「待修改图」放在第 1 位，参考图跟后面，所以：

- 主体构图来自「待修改图」
- 风格 / 场景 / 人物设定来自「参考图」

> 实测：用纯红图 + 蓝白图验证 —— 要求"用第二张的配色改第一张"，
> 输出确实是"保留第一张的构图，配色取自第二张"。

### 不用参考图时

直接 `Ctrl+D`，就用「待修改图」自己（等同旧的单图改图行为）。

### 左下角为什么不是预览了？

原来左下是字符画预览，但真机反馈"字符画没有意义"。
现在改成上面这个**参考图管理面板**。

想看原图请按 **`Ctrl+L`** —— 优先调系统看图器（`termux-open`），
失败时在 TUI 内弹全屏浮层（支持 `↑↓` 滚动、`f` 切换缩放）。

## 八、常见问题

### 打开后黑屏 / 没有任何输出
终端编码问题。先跑诊断：

```bash
python3 main.py --doctor
```

### 按键没反应
功能键都是 **Ctrl 组合**。Termux 软键盘的 `CTRL` 键在左下角，
长按可以固定显示。按 `Ctrl+T` 看完整键位表。

### `ImportError: attempted relative import with no known parent package`
直接打开了 `impydroid/` 里的模块文件。正确入口是同目录的 `main.py`。

### 预览很小 / 看不清
默认已经是"填满面板"策略。若想严格保持宽高比：
`IMGAGENT_TUI_FIT=ratio python3 main.py`。

### 生成后界面变慢
旧版本（≤5.6.0）有此问题，5.7.0 已修复（预览渲染缓存）。
若仍遇到，可设 `IMGAGENT_TUI_COLOR=off` 进一步降低开销。

### 提示词打不出 `q` / `3` 等字符
旧版本（≤5.6.0）有此问题，5.7.0 已修复（功能键改为 Ctrl 组合）。

## 九、常见问题

### 报错「403 Forbidden」或「402」怎么办？

**八成是余额不足，不是权限问题。**

APIMart 对"余额不足"用**两种状态码**（不同网关）：

| 状态码 | 响应体 |
|---|---|
| `402` | `insufficient balance (current: 0.02 USD, required: 0.05 USD)` |
| `403` | `insufficient balance: insufficient quota: balance=38650, required=42383` |

**为什么文生图能成功、编辑却失败**：
- 文生图 low 1k 约 **$0.005–0.013**
- 编辑（带参考图）**预扣按最高档算**，约 **$0.05**（要传参考图，输入 token 更多）

v5.17.0 起，这两种错误都会被翻译成：

```
编辑失败：insufficient balance: ... (HTTP 403/quota_not_enough)
  → 账户余额不足（当前 $38650，需要 $42383）—— 去 APIMart 充值；
    编辑比文生图贵（要传参考图）
```

### 想省钱怎么办？

| 键 | 省法 |
|---|---|
| `Ctrl+E` | 用 `1k`（默认，最便宜） |
| `Ctrl+P` | 用 `low` 档 |
| `Ctrl+A` | 设 `1` 张 |
| `Ctrl+U` | 用 `jpeg`（文件小，但云端计费不变） |

**离线模式**（`IMGAGENT_FORCE_OFFLINE=1`）完全不花钱，用占位图跑通流程。
